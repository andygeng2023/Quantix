Why were clicks broken?

The previous interface mixed generated HTML with incomplete event binding. This build uses delegated navigation and real buttons throughout.

How do I get data?

Run the Python API with yfinance, then put its address in Settings. No market-data key is required for this build.

What are the scores?

They are historical quantitative research statistics, not guaranteed outcomes or trading instructions.
